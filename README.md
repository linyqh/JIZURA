# JIZURA 字面 — 歌词动态视频（文字PV）自动编排工具

**语言：** [English](README.en.md)　／　[한국어](README.ko.md)　／　[Bahasa Indonesia](README.id.md)　／　[Tiếng Việt](README.vi.md)　／　**简体中文**：[打开网页版](https://852wa.github.io/JIZURA/zh-hans/)　／　**繁體中文**：[開啟](https://852wa.github.io/JIZURA/zh-hant/)

英文版 AE 面板：[ScriptUI](https://852wa.github.io/JIZURA/JIZURA_AE_en.jsx) · [CEP](https://852wa.github.io/JIZURA/JIZURA_CEP_en.zip)

输入歌词，它会把文字PV（歌词动态视频 / Lyric Motion）中常用的表现手法组合起来，自动编排镜头，并导出为 MP4。这是一个浏览器应用。排版、动作、装饰、转场、后期处理被拆成 860 个小部件（以及 27 种风格），每次的组合都不同，换一个种子就能得到完全不同的编排。同时附带 After Effects 面板（脚本版，以及可直接使用浏览器版界面的 CEP 版）。

**版本：v0.9.0**（更新记录见 [CHANGELOG.md](CHANGELOG.md)）

**▶ 在浏览器中使用：<https://852wa.github.io/JIZURA/zh-hans/>**　／　AE 面板：[JIZURA_AE.jsx](https://852wa.github.io/JIZURA/JIZURA_AE.jsx)（脚本版。在链接上右键 →「链接另存为」）・[JIZURA_CEP.zip](https://852wa.github.io/JIZURA/JIZURA_CEP.zip)（CEP 版）

- 无需安装。歌词、歌曲、导出全部在浏览器内处理，不会上传到服务器（唯一从外部加载的是 Google Fonts 字体，且只加载当前编排用到的字体）。
- 「一键生成」按钮（快捷键 `R`）：每按一次，风格、氛围、动作、配色、编排都会整体重新决定。
- 画面比例 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 4:5 / 21:9，分辨率 720p〜4K，帧率 24 / 30 / 60fps。
- 载入歌曲后会检测节拍并让镜头对齐节拍，也可以通过轻点手动同步。
- 可导出 MP4（含歌曲）・序列 PNG・透明 PNG。背景还可设为**绿幕 / 黑底**（只有白色文字和特效），作为合成素材导出。也可以导出能在 After Effects 中编辑的编排数据（JSON）。

<summary><h3>运行环境</h3></summary>

- **MP4 导出**：需要支持 WebCodecs 的浏览器（推荐 Chrome / Edge。Safari 16.4 及以上、Firefox 130 及以上也支持 WebCodecs，但能否以 H.264 导出取决于浏览器和操作系统）。在不支持的环境中，仍可使用预览和序列 PNG 导出。
- 手机也能使用（iPhone 需 iOS 16.4 及以上的 Safari，Android 使用 Chrome）。以高分辨率导出长歌曲时，建议使用电脑。
- 字体只在需要时从 Google Fonts 加载用到的字体（离线时用电脑上的字体代替）。

<details>
<summary><h2>一键生成（简易模式）</h2></summary>

可通过右上角的「简易 / 详细」切换界面。首次打开时为简易模式（手机上为「手机」模式，见下文「手机模式」）。

- **一键生成**（也可按键盘上的 `R`）：每按一次，会把下面这些内容一起随机重新决定，并从头播放。
  - 风格（不会与上一次相同）
  - 氛围（故障 / 沉静 / 流行 / 平面设计 / 杂志编辑 / 情感 / 全包含。开启「也使用恐怖特效」时还会包含恐怖）。每种氛围会改变动作强度、故障量，以及使用的排版和入场・退场手法。
  - 标题和明朝框的字体
  - 配色（有时强调色和偏移色 A/B 也会随机变化）
  - 镜头编排（种子）
- **◀ 上一个方案 / 下一个方案 ▶**：可以在一键生成产生的方案之间来回切换。回到喜欢的方案后再导出。
- **只换这一项**：保留当前方案，只重新抽取其中一部分。
  - 风格 / 配色（强调色・偏移色 A/B）/ 氛围（动作与使用的手法）/ 编排（排版与动作的组合）
- 歌词、歌曲、时间点、导出设置不会因一键生成而改变。在行列表中锁定的行也会原样保留。

<details>
<summary><h3>随机使用的特效范围</h3></summary>

一键生成按钮下方（详细模式下在「手法」标签页上方）的复选框，用来决定一键生成、洗牌、逐行重新抽取时会选中哪些特效。

- **使用新增特效**（初始：关）：关闭时，只使用最初公开版本的特效（356 个部件・12 种风格）。开启后，后来新增的特效（351 个部件・12 种风格・6 种字体）也会成为候选。
- **使用和风特效**（初始：开）：灯笼・明信片・障子・扇子・家纹・青海波・樱花花瓣等和风图形，以及和风风格（樱花・墨与朱）。关闭后不会被选中。此判定在「新增」复选框之后生效。
- **使用文字PV类部件**（初始：开）：由最初公开版部件衍生、仅靠线条・数字・字组来表现的部件（50 个）。以文字本身为主角，而不是图画或图案（大字夹排・出血大字・十字组・注音标注・栏线组・字号递增・宽度对齐・切分・行内强调・重打・括号展开/闭合・页柱与页码 等）。在「手法」标签页中带有「文」标记。
- **使用动态文字（Kinetic）部件**（初始：开）：逐词运动、以动作为重的部件（51 个）（堆叠・直角转弯・互换・潜入文字・流动对齐・逐词切镜・齿轮・正面碰撞・逐词重击・铰链放下・逐词踩拍・跟读镜头・刻切 等）。有歌曲节拍时，词的切换会对齐节拍。带有「キ」标记。
- **也使用恐怖特效**（初始：关）：营造诡异氛围的部件（52 个），以及 3 套配色（废墟・深夜录像・诅咒之信）（手电筒・门缝・墙上涂鸦・监控屏幕・降灵盘・寻人启事・只有一个字不同・涂黑文件・雪花电视・灵异照片・影子不对、眨眼之间・弹出・镜像文字、拖入・只剩一个字、痉挛・凝视的字、注视的眼睛・魔法阵・裂纹、昏暗走廊・扩散的污渍、惊恐的手持、潜意识闪帧・掠过的影子、雪花切镜・眨眼 等）。开启后，一键生成的氛围里会加入「恐怖」，大约一半概率出现恐怖方案。一键生成时，恐怖部件只在氛围为「恐怖」时使用。带有「ホ」标记。不含血、伤口等残酷表现。
- 这 3 项是与「新增」独立的复选框，即使新增关闭也可使用。
- 无论哪一项，在手动指定了某行的排版等，或自己选择了风格时，都不受此限制，照样可以使用。
- 在「手法」标签页和风格列表中，新增的带有「追加」标记，和风的带有「和」标记。按当前设置不会被随机选中的会显示得较淡。

在手机（窄屏或触控设备）上，右上角会变成「手机 / 简易 / 详细」三项，首次打开时为手机模式。

- **行折叠显示**：行列表只逐行显示歌词，点按某一行会展开该行的骰子・锁・镜头数等。点按标题，可以按歌词・行列表・设置分组折叠或展开。
- 保存・打开・初始化等收在「菜单」里。按钮大小便于手指点按。
- **不易导出失败的设置**：手机模式下，初始导出分辨率为 720p。即使选了大于 1080p 的分辨率，手机模式也会以 1080p 导出（更大的分辨率请在「详细」模式下使用）。导出期间会保持屏幕常亮，切换到其他应用期间也不会判定为失败。导出后，在支持的浏览器中可以通过「分享并保存」存入相册等。

<details>
<summary><h2>浏览器版的使用方法</h2></summary>

1. **歌词**：1 行为 1 个短句。记法如下。
   - `夜明けの色を/覚えてる` … 用 `/` 指定镜头的切分点
   - `*透明*` … 强调（更容易选中大号、冲击力强的特效）
   - 行末的 `!` … 加入闪光和抖动
   - `歌词|注释` … 显示在注释排版中的小字
   - `[01:23.45]歌词` … 直接使用 LRC 时间戳。没有时间的行，会保持书写位置，落在前后时间之间
   - 歌词栏右上角的「读取 LRC」可以把 .lrc 文件作为歌词载入（替换当前歌词，可用「撤销」恢复）
   - `[间奏 8]` … 8 秒的间奏。不显示歌词，只流动背景・装饰・画面特效（6 秒以上会小字显示曲名与艺术家）。省略秒数时为 4 秒，可通过轻点同步或标记来调整长度。`[interlude]` `[间奏]` `[간주]` 同样有效
2. **歌曲与时间点**
   - 载入歌曲后，会自动检测 BPM 和节拍，并把镜头切分点贴近节拍。载入的歌曲会保存在此浏览器中，重新打开页面时自动重新载入（避免导出时丢失音频）。
   - 按下「轻点同步」后歌曲开始播放。在每一行开始的瞬间按 Space。按错了按 Backspace 或「退回一步」。点击行列表中的 ◎，可以**从该行重新轻点**（前面行的时间保持不变）。
     - 轻点期间可以通过「速度」降到 0.75× / 0.5× 来听（保存的时间是歌曲的原始时间）。开启「倒计时」后，在 3・2・1 之后歌曲才开始。
     - 一行中有多个镜头时，在镜头切换的瞬间按 Tab，可以同时对齐该行各镜头的起始时间。
   - 也可以直接修改行列表中的秒数。会与前后行顺序互换的数值，请改到不会互换的位置。
   - **镜头起始时间**（详细模式）：行下方每个镜头的栏位里，会显示第 2 个及以后镜头的起始时间。输入数值为固定，清空则恢复自动。正在播放的镜头用边框标示。
   - **时间轴**：左右拖动上方刻度（行的分隔），可以改变该行的开始时间（吸附到节拍，按住 Shift 可自由移动）。＋／−・滚轮缩放，Shift＋滚轮左右移动，点「全体」还原。
   - 歌词和时间点的修改可以用「撤销」（Ctrl+Z）取消。
3. **逐行修改**（简易模式也可使用）
   - 点 ✎（或双击歌词），可以就地修改该行歌词。记法同样可用。
   - 通过「镜头 自动 / 1〜6」，可以决定该行分成几个镜头。
   - 用每行的骰子只重新抽取该行。用锁固定该行的编排，也可以直接指定排版（详细模式）。上了锁的行，即使对其他行掷骰子・洗牌・一键生成，排版・动作・装饰・配色・镜头划分也都原样保留。
   - 用「洗牌」重新抽取整体。
   - **主题**：在一键生成按钮旁（简易模式下在下方）的「主题」中选择 文字PV / 动态文字 / 和风 / 恐怖 / 流行 / 抒情，就会在该方向内随机。所需部件的开关（文字PV类・动态文字・和风与新增・恐怖）会随之打开。选「无主题」则与以往相同。
   - **逐镜头替换**（详细模式）：点预览下方的镜头信息（排版・入场・保持・退场・装饰・加工・背景・镜头运动・转场），会打开列表，可以只把该镜头换成别的部件。选「自动」即恢复。在行列表中，行下方也会出现按镜头选择排版的栏位。通过「洗牌／一键生成此镜头」，可以只重新选择该镜头。替换后，其他镜头的抽取结果不会改变。
   - **锁定**（详细模式）：用「手法」标签页中各分类的锁，可以在一键生成之后保留该分类的 ON/OFF 选择；用「特效」标签页中滑块・闪光・抽帧的锁，可以保留其数值。锁定状态也会保存在项目文件中。
   - **循环**：每按一次播放按钮旁的「循环」，会依次切换 全体 → 行 → 镜头 → 无。行・镜头循环时，时间轴上会显示重复的范围。
4. **风格**：配色・字体・质感的组合共有 27 种（包括 樱花 / 深海 / 夕阳渐变 / 森之手帐 / 蒸汽波 / 报纸 / 合成器80s / 牛皮纸 / 糖果 / 酸性 / 墨与朱 / 金夜，以及恐怖用的 废墟 / 深夜录像 / 诅咒之信 等）。同一个视频中，背景色也会随镜头切换。
   - 字体从 Google Fonts 的 18 个字族中选取（包含 Reggae One / Rampart One / Potta One / Kiwi Maru / Klee One / Shippori Mincho B1）。由于**只加载当前编排用到的字体**，即使字体数量增加，启动和运行也不会变慢。
   - 字体可以用以下方法替换。
     - 输入电脑上已有的字体名
     - 载入 .ttf / .otf 文件
5. **特效与手法**
   - 在「特效」标签页中，调整动作强度・故障・色彩偏移・装饰量・镜头细分程度・质感・抽帧。
   - 通过「隐藏装饰数字」「隐藏装饰时间」，可以不显示排版、装饰・HUD 附带的 `No.01`、`00:12.34` 之类的文字（歌词中包含的数字・时间不受影响）。
   - 在「手法」标签页中，可以逐个开关 10 个分类（排版・入场・保持・退场・装饰・文字加工・背景・镜头运动・画面特效・镜头间转场）的部件（与上面的「新增」「和风」复选框组合判定）。按分类折叠，可使用「全部 ON / 全部 OFF / 反选」和按名称筛选。
6. **导出**
   - MP4（Chrome / Edge 为 H.264。可包含歌曲）
   - 序列 PNG（ZIP）
   - 透明 PNG（ZIP・无背景。用于 AE 等合成）
   - 序列 PNG・透明 PNG 也可以从简易模式的导出中选择。
   - 歌词（LRC）：导出带有每行开始时间的 .lrc。选定了导出范围时，只导出这些行，时间从视频开头起算。
   - 在「背景」中选择**绿幕 / 黑底**，就成为只有白色文字和特效的合成素材（详见下文「合成用背景」）。
   - 画面比例可选 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 4:5 / 21:9，分辨率 720p〜4K，帧率 24 / 30 / 60fps（详见下文「以 24 / 30 / 60fps 导出」）。
   - **只导出选定的行**：在「导出范围」中选择起止行，或点行列表中的 ⇥（Shift＋点击扩大范围）。文件名会带上 `_L03-05` 这样的行号。
   - **更不容易导出失败**：采用边写边生成的方式，长歌曲以及 1080p・1440p 也不会一次占用大量内存。GPU 编码器失败时，会自动切换到软件编码器重新写入。
   - **大视频用（直接保存到文件）**：在 Chrome / Edge 中，有先选择保存位置、再直接写入的按钮。以高分辨率导出长歌曲时请使用它。
   - 音频：浏览器无法以 AAC 导出时（变成 Opus 或无法导出音频的情况），由于在 iPhone 或 QuickTime 上可能没有声音，会同时把等长的音频另存为 WAV。
- **统一感**（「特效」标签页／简易模式的复选框）：开启后，按文字PV的惯用做法来编排。
  - 按段落（用空行分隔的一组）统一排版・动作・镜头运动・装饰。重复的歌词（副歌等）会以与第一次相同的方式回来。
  - 动作方向交替（左→右、上→下），强烈的动作留给关键的行。
  - **定格（キメ）**：行末带 `!` 的行（没有的话，取重复段落的首行），用 1 个镜头大胆呈现（大字・闪光・缩放・抖动）。
  - **变形（モーフ）**：向同一行的下一个镜头过渡时，相同的字移动，其他的字溶解变化。
  - **粗细**：有时以从细体长成粗体的方式显示（Noto Sans / Serif JP 的可变字体）。
- **字组整理**（同一位置的复选框）：收紧假名字距让它成块阅读，把助词（は・が・を・に 等）变小、行首字变大，英文字母略放大并与日文之间稍留空隙。文字比声音提前 0.2 秒出现，并避免叠加过多效果（装饰最多 1 个，画面特效每个镜头最多 1 个）。
  - 两者都保留了原有的排法，取消勾选即与以往相同。AE 面板会带入被选中的排版・动作・时间点（字距・字大小的调整、粗细、变形在 AE 中会是相近的表现）。
- **中央留空（用于角色）**：「导出」设置中的复选框。以在中央叠放角色等为前提，把歌词分成两部分，横屏时放在左右，竖屏时放在上下的条带中（例：「花」｜「开了」。条带在横屏时约占宽度的 36%，21:9 为 30%，竖屏为高度的 33%）。左右（上下）是同一排版・动作・装饰・镜头运动的一个场景，后半部分会稍微延迟出现。背景与画面特效仍是整个画面，不使用把歌词大幅画在背景上的背景（大号单字）。只有一个词的短行，两侧显示相同的词。竖屏时可通过「竖屏时」选择上下分还是左右分（左右时条带为宽度的 34%）。预览中用虚线显示留空范围（不会进入导出）。AE 面板（脚本版的「从歌词」、CEP 版、JSON）中也是相同布局。
- **界面固定显示**：在宽度・高度足够的屏幕上，整个页面不滚动，中央的预览和时间轴始终可见。歌词・行列表（左）和设置（右）在各自的列内滚动。播放期间，行列表会自动跟随当前行（刚滚动列表后会暂停）。窄屏则与以往一样整页滚动。
- **清除歌词／初始化**：「清除歌词」（歌词栏右上角）会清除歌词，以及逐行的时间点・指定・导出范围。可用「撤销」或 Ctrl+Z 恢复。顶栏的「初始化」会清除歌词・歌曲（包括保存在此浏览器中的）・设置・方案历史・撤销历史，恢复到最初状态（确认后执行，无法撤销）。显示模式・音量・界面语言保持不变。

7. **导出到 AE**：把当前编排（时间点・排版・特效・配色）导出为 JSON。在 AE 面板中载入后，会生成保持相同编排、可继续编辑的合成。

<summary><h3>以 24 / 30 / 60fps 导出</h3></summary>

1. 在「导出」标签页（简易模式下为右侧的「导出」栏）中，选择画面比例・分辨率・**fps**。
2. 点「导出 MP4」。会按所选 fps 的帧数直接导出（例：6 秒在 24fps 下为 144 帧，在 60fps 下为 360 帧）。
3. 动作的卡顿程度与 fps 无关，由「特效」标签页的**抽帧**决定。
   - **2 帧一拍（每秒 12 张）**：带有文字PV风格的轻微卡顿动作。无论以哪种 fps 导出，看起来都相同（默认）。
   - **3 帧一拍（每秒 8 张）**：更像手绘动画、偏停顿的动作。
   - **全帧**：按输出 fps 每帧都动。60fps + 全帧最为流畅（镜头运动和流动的色带更漂亮）。
4. 故障和闪烁的随机切换，即使改变 fps，也以 24fps 为基准保持相同速度。以 60fps 导出，闪烁也不会变成两倍速。
5. 参考：YouTube / MV 用 24fps（或 30fps），想让社交平台的竖屏视频更流畅时用 30〜60fps + 全帧。60fps・4K 的导出会花较长时间。

在 AE 面板中，可以通过面板的「fps」（24 / 30 / 60）选择合成的帧率。从 JSON 生成时，会使用浏览器版所选 fps 的合成。

</details>

<summary><h3>合成用背景（绿幕 / 黑底）</h3></summary>

想把歌词单独叠加到实拍或插画视频上时使用。

1. 在「导出」标签页（简易模式下为右侧的「导出」栏）的**背景**中，选择以下之一。
   - **通常**：保持风格的配色・背景（默认）
   - **绿幕**：`#00FF00` 之上只有白色文字和特效
   - **黑底**：`#000000` 之上只有白色文字和特效
2. 预览中也会原样反映（右上角会显示「绿幕」等）。无论以 MP4・序列 PNG・透明 PNG 哪种方式导出，效果都相同，文件名末尾会带上 `_greenback` / `_blackback`。
3. 合成方法
   - 绿幕：用视频剪辑软件的色键功能（Premiere Pro 的 Ultra 键、DaVinci Resolve 的 3D 键控器、AE 的 Keylight 等）抠掉绿色。
   - 黑底：把混合模式设为**滤色**（或相加）叠加，或用亮度键抠掉黑色。
   - 以透明 PNG 导出，则一开始就是背景透明的白色素材。

**透明 PNG 前景／后景（ZIP）** 会把每一帧的 2 张透明 PNG 导出到 zip 内的不同文件夹。
   - `back/`：后景（背景图形，以及放在歌词后面的装饰）
   - `front/`：前景（歌词、其周围的装饰・边框、色彩偏移的重影、HUD）
   - 作用于整个画面的特效（闪光・分屏等）对两者同样生效，所以把 `front` 叠在 `back` 上就是正常的外观（不包含背景色・纸张质感・发光・扫描线）。

在透明 PNG 中，作用于整个画面的特效（反色・闪光・频闪・色相偏移・分屏・上下滑动・显像管关机・黑帧等）也不会涂满背景，只作用于文字和装饰部分（黑帧・白帧的那一帧会成为空的透明帧）。

- 文字・装饰・特效全部为白〜灰的单色。风格的配色、背景花纹、纸张质感、颗粒、暗角都不会出现（编排・动作・特效的组合与「通常」时相同）。
- 色彩偏移的重影和光晕以灰色绘制，抠像后会变成半透明。绿幕的做法是让效果与「黑底以滤色合成时」相同。
- 闪光・反色・频闪等作用于整个画面的特效，会保持为白光。如果不需要，请在「特效」标签页中关闭闪光或减弱故障，或在「手法」标签页的「画面特效」中单独关闭。
- 在 AE 面板中，也可以通过面板的「背景」选择同样的设置。「导出到 AE」的 JSON 中也包含背景设置。

</details>

<summary><h3>使用方法</h3></summary>

- **从歌词**：确定歌词・风格・尺寸・特效后，点「生成合成」。
  - 时间点可以从以下 3 种中选择。
    - 自动（根据字数・BPM 计算）
    - 所选图层的标记
    - 合成标记
  - 推荐步骤：选中歌曲图层，边播放边用小键盘的 `*` 在每一行开头打标记。选择「使用所选图层的标记作为行首」后生成。
- **一键生成**：每按一次，会随机决定风格・氛围・特效强度・2 帧一拍/闪光/HUD・种子・配色，并反映到面板显示中，创建新的合成。喜欢结果的话，可以在此基础上调整数值，再点「生成合成」重新创建。
- **氛围**（「特效」栏）：选择后，会收窄到适合该氛围的排版・入场・退场手法来编排。收窄到哪些手法由种子决定，因此种子相同则结果相同。
- **强调色・偏移色**：用「随机配色」重新选择强调色和偏移色 A/B。也可以直接输入 `#RRGGBB` 格式。勾选了「覆盖风格颜色」时，会应用到生成合成的所有场景（明度会根据背景自动校正）。
- **新增・和风・部件集・背景**：可以选择与浏览器版相同的「使用新增特效」「使用和风特效」「使用文字PV类部件」「使用动态文字部件」「也使用恐怖特效」复选框，以及「背景」（通常 / 绿幕 / 黑底）。27 种风格全部可选（列表中的〔追加〕〔和〕〔ホ〕是标记）。恐怖开启时，氛围中会加入「恐怖」。
- **支持的部件**：浏览器版的 860 个部件全部支持（排版 184・入场 125・保持 52・退场 109・装饰 130・文字加工 62・背景 66・镜头运动 36・画面特效 69・镜头间转场 27。v0.9.0 中也加入了文字PV类・动态文字・恐怖的 153 个部件），用 AE 的文字图层・形状图层・蒙版・效果・表达式来构建。无论哪个部件，歌词都保持为文字图层，之后可以重新输入。
  - 逐词运动的动态文字部件，在 AE 中用逐词的文字图层（或一个文字图层的逐字动画器）来构建。与歌曲节拍对齐的部分，在 AE 中是把镜头长度均分后驱动。
  - 3D 旋转、纸张翻页式的动作，以及像素级加工（像素排序・抖动等），用 AE 标准效果和 2D 变换替换为相近的外观。
  - 如果 JSON 中含有面板不认识的部件名（今后浏览器版新增的部件等），会替换为最接近的部件来构建，并在面板下方的状态栏显示「有替换」。
- **尺寸**：1920×1080 / 1080×1920 / 1080×1080 / 3840×2160 / 1280×720 / 1440×1080（4:3）/ 1080×1440（3:4），或与活动合成相同的尺寸。
- **从 JSON**：载入用浏览器版的「导出到 AE」生成的 JSON。在浏览器中确定的编排，会原样在 AE 中搭建出来。
- **字体**
  - 如果安装了 Noto Sans JP / Noto Serif JP / Dela Gothic One 等，会自动使用（自动选择仅限 AE 2024 及以上）。
  - 没有安装时，使用「字体」标签页中指定的字体。默认为游ゴシック・游明朝。

- **轻量**（让 AE 中的播放更轻）：省略色彩偏移的复制・纸张质感・发光・颗粒・复制图像的画面特效来创建。图层数约减少 4 成，即使是长歌曲，在 AE 中播放也更轻。
- **长歌曲**：合成会分小步骤创建，所以创建过程中 After Effects 也不会「无响应」。面板上会显示进度（％・镜头数），按**中止**，会用到此为止已创建的镜头完成合成（脚本版・CEP 版均可）。由于撤销被分得很细，重新创建时请在项目面板中删除合成和 `cuts` 文件夹。

- **诊断报告**（「从 JSON」标签页）：让 AE 计算最后创建的合成中的表达式，把错误和替换汇总保存到 `JIZURA_report.txt`。如果没有得到预期结果，请附上这个文件反馈。

</details>

<summary><h3>CEP 版（在 AE 中使用浏览器版界面）</h3></summary>

1. 下载 [`JIZURA_CEP.zip`](https://852wa.github.io/JIZURA/JIZURA_CEP.zip) 并解压。
2. Windows 运行 `install_win.bat`，Mac 运行 `install_mac.command`（会复制到用户的 CEP 扩展文件夹，并设置为可以加载未签名的面板）。
3. 重启 After Effects（2022 及以上），打开**窗口 → 扩展 → JIZURA 字面**。

- 歌词・风格・特效的决定方式与浏览器版相同。点**在 AE 中生成合成**，当前编排的合成会当场创建。
- 在**导出范围**中事先选好行，就只会为这些行创建合成（歌曲也会按相同位置放入）。想把长歌曲分几次创建时可以使用。「导出到 AE」的 JSON 也是相同范围。
- **AE 中选中的歌曲**：在 AE 中选中歌曲图层后点按，会分析该歌曲并对齐节拍。合成中也会放入这首歌曲。
- **用 AE 标记作为行首**：把所选图层（没有则为合成）的标记，作为各行的开始时间。
- MP4・序列 PNG 的导出也可以直接在面板中使用（保存位置通过对话框选择）。
- 更详细的安装方法，以及发布用的带签名 `.zxp` 的制作方法，见 zip 中的 `README_CEP.md`。

</details>

<details>
<summary><h3>生成的内容</h3></summary>

- 每个镜头的预合成（`JIZURA <曲名> cuts` 文件夹）
  - 根据部件的不同，镜头中还会创建更多预合成（`JZ … art` 等），以及色彩偏移用的副本（`… ghost`：去掉了纸张或板子等背景物的版本）。
- 创建完成时，会删除所有未使用的隐藏图层。剩下的隐藏图层只有轨道遮罩（按 AE 的规则，用作遮罩的图层本身不显示）。
  - 文字通过文字动画器（表达式选择器）运动，所以重新输入文字后动作也能保持。
- 色彩偏移是把每个镜头按时间差复制，用「色调」效果着色的重影图层来表现。
- 最上层的 `JZ FX` 调整图层汇总了以下内容。
  - 2 帧一拍（色调分离时间）
  - 抖动（变换）
  - 切片故障（波形变形）
  - 缩放模糊 / 反色 / 发光 / 噪点
- 还会生成 `JZ Flash`・`JZ Vignette`・HUD（时间码・行计数器）。
- 背景设为绿幕 / 黑底时，最上层会放入 `JZ Key Mono`（用色调变为单色的调整图层）来代替 `JZ Vignette`，绿幕时还会加入 `JZ Key Green`（混合模式：滤色）。

</details>

<details>
<summary><h3>注意</h3></summary>

- AE 2020 及以后，假定表达式引擎为 JavaScript（新项目的默认值）。
- 本面板是在模拟 AE 对象模型的环境中验证的。已确认：707 个部件分别以多种字数・画面比例构建且无错误；所有风格 × 多个种子的一键生成无错误；与浏览器版相同编排对比，外观和动作一致。但尚未在真实的 AE 中运行过。如果在效果设置等方面出现意料之外的情况，会在生成后以列表显示该项目，并继续生成其他部分。
- 部件较多的镜头，图层和表达式也会较多。长歌曲的生成和预览可能会花较长时间（把预览分辨率调到 1/2〜1/4 会更轻）。

<summary><h2>开发・构建</h2></summary>

```
python3 build.py              # src/ app/ vendor/ → index.html / en/index.html / ko/index.html
node tools/export_ae_data.js  # 修改 src/ 后：更新 ae/data.json（AE 面板使用的风格・部件信息）
python3 build_ae.py           # ae/（主体 + 已移植的包 ae/p_*.jsx）→ JIZURA_AE.jsx
python3 build_cep.py          # index.html + ae/ + cep/ → build/com.852wa.jizura/ 与 build/JIZURA_CEP.zip（发布用的复制到根目录）
```
版本写在仓库根目录的 `VERSION` 中（构建时会写入界面・AE 面板・CEP 版）。修改后请同时在 `CHANGELOG.md` 中追加记录。要把 README 的标题做成折叠形式，请使用 `python3 tools/fold_readme.py README.md`（新的标题请以 `<details>` 的形式补写）。

构建只需要 Python 3 和 Node.js（不需要 npm 包）。AE 面板的测试（在模拟 AE 对象模型的环境中构建所有风格）可在 `cd dev && npm install` 之后，通过 `node dev/ae_test.js` 运行。添加表现部件时，请参考 `docs/EXPRESSION_PACKS.md`（测试用工具在 `dev/`）。
